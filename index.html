API REST

Integre o encurtador de links em suas aplicações com nossa API simples e rápida.

POST /api/shorten 
curl -X POST https://short.link/api/shorten \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://exemplo.com/pagina",
    "slug": "minha-pagina",
    "expires": "7d"
  }'
GET /api/stats/{slug} 
curl https://short.link/api/stats/minha-pagina
